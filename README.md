# Grading System

A plain PHP and MySQL grading portal for managing academic records.

## Roles

- **Admin:** manages users and system data.
- **Teacher:** manages and records grades.
- **Student:** views grades and academic information.

## Features

- Role-based authentication and dashboards
- Student record and grade management
- Grade viewing for students
- Admin and teacher management views

## XAMPP Setup

1. Install and start Apache and MySQL in XAMPP.
2. Place this project in `C:\xampp\htdocs\Grading_System`.
3. Open phpMyAdmin at `http://localhost/phpmyadmin`.
4. Create a MySQL database, then import `sql/schema.sql`.
5. Update the database settings in `includes/config.php`.
6. Open `http://localhost/Grading_System/login.php`.
